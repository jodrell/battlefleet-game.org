# BFG:R Source files

This directory contains the original source PDF files, obtained from https://linktr.ee/bfg.remastered, plus the plaintext of those files, extracted using [`pdf2text.py`](pdf2text.py).

This directory exists so that if/when the PDFs are updated, a "diff" of the text can be generated easily, to produce patches that can be applied to the Markdown files in [../docs](../docs).
