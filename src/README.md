# BFG:R Source files

This directory contains the original source PDF files, obtained from https://horizon-bfg.infinityfree.me/, plus the plaintext of those files, extracted using [`pdftotext`](https://linux.die.net/man/1/pdftotext).

This directory exists so that if/when the PDFs are updated, a "diff" of the text can be generated easily, to produce patches that can be applied to the Markdown files in [../docs](../docs).
